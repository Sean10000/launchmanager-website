Mac 释放端口

端口已被占用时，安全找到所属进程并停止——包括 Docker 容器。

快速修复（将 PORT 换成实际端口）

lsof -nP -iTCP:PORT -sTCP:LISTEN
kill <PID>

仅在进程不响应正常终止信号时使用 kill -9。

常见情况

  • 残留的 Node/Vite 进程 — 结束 lsof 显示的 node 进程。
  • Docker — 监听可能是 com.docker.backend；用 docker stop 停止容器。
  • launchd 任务 — 在 LaunchManager 中卸载 LaunchAgent/Daemon，避免子进程被反复拉起。

在 LaunchManager Services 中按端口查看进程名、PID 及是否由 Docker 占用，无需猜测 PID。

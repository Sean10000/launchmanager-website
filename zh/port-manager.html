macOS 端口管理

查看本机所有 TCP 监听、匹配端口与进程、解决冲突——无需死记 lsof 参数。

常见问题

启动开发服务器时出现 EADDRINUSE。3000、5173 或 8080 端口已被占用——但活动监视器不显示端口，lsof 输出又难读。

终端做法

# 查看 3000 端口
lsof -nP -iTCP:3000 -sTCP:LISTEN

# 所有 TCP 监听
lsof -nP -iTCP -sTCP:LISTEN

在输出中找到 PID，执行 kill <PID>。若是 Docker 代理进程，应停止容器而非误杀代理。

LaunchManager 图形界面

打开侧边栏 Services。每 3 秒刷新本地 TCP 监听，显示进程名、PID，并为 Docker 容器标注镜像与 Compose 项目。可重命名任意行，标签重启后保留。

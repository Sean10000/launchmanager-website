Mac Docker 端口

Docker 通过代理进程绑定主机端口——将容器映射到 localhost 并解决与开发服务的冲突。

常见问题

docker ps 能看到端口映射，但当 5432 或 3000 被占用时，不一定清楚是哪个容器或残留代理占用了套接字。

终端做法

docker ps --format "table {{.Names}}\t{{.Ports}}"
lsof -nP -iTCP:5432 -sTCP:LISTEN

LaunchManager 图形界面

Services 扫描器支持 Docker 感知：容器行显示名称、镜像与 Compose 项目。可为技术栈重命名行（如「postgres-dev」），用 docker stop 停止容器，避免误杀 Docker 代理 PID。

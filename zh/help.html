快速上手

四步即可掌控 launchd 任务。

  1. 在侧边栏选择范围：用户代理、系统代理或系统守护进程。
  2. 点击 + 创建任务，或点击铅笔图标编辑。
  3. 使用行内按钮加载、启动或停止任务。
  4. 展开行查看详情和日志输出。

主题

Launchd 任务

在侧边栏浏览用户代理、系统代理和系统守护进程。通过引导表单创建任务，或直接编辑 plist 字段。在列表中加载、启动、停止——系统级操作需要时会提示管理员权限。

Services（TCP 监听）

在侧边栏打开 Services，扫描本地 TCP 监听（每 3 秒刷新）。Docker 容器显示名称、镜像和 Compose 项目。任意行可重命名为自定义标签，重启后保留。使用 docker stop 停止容器，避免误杀代理进程。

调度

创建或编辑任务时，在同一表单中设置间隔、日历、登录启动或保活选项，满足大多数日常调度需求。

Login Items

在 Login Items 视图中查看配置为登录时打开的应用，与 launchd 任务一并浏览。

故障排除

  • 损坏或空的 plist 会在列表中行内提示，支持一键删除。
  • 若 Docker 操作失败，请确认 Docker Desktop 或 Colima 正在运行。应用会搜索常见安装路径并回退到 PATH。
  • 已加载的任务在退出 LaunchManager 后仍由 launchd 运行——应用仅用于配置和控制。

常见问题

关于 LaunchManager 的常见问题。

LaunchManager 是什么？

一款原生 macOS 后台服务控制中心——在同一 GUI 中管理 LaunchAgents、LaunchDaemons、Login Items、本地 TCP 端口与 Docker 容器，无需手写 plist 或运行 lsof。

退出应用后，任务还会继续运行吗？

会。已加载的任务由 launchd 负责运行，LaunchManager 仅用于配置和控制。

可以管理系统级任务吗？

可以，在需要时会提示输入管理员密码。

运行需要什么环境？

macOS 14 及以上，可通过 Homebrew、DMG 或从源码构建安装。

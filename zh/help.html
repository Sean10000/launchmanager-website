快速上手

五步即可掌控 launchd 任务。

  1. 在侧边栏选择 Launch Agents、Login Items 或 Services。
  2. 导入 .plist 或粘贴 XML（也可从 New 菜单新建）。
  3. 用表单或 XML 编辑；保存后用行内操作加载 / 启动 / 停止。
  4. 展开行查看详情与日志；需要时从菜单克隆。
  5. 在 Services 中管理本机监听，或从运行中的进程创建 Launch Agent。

主题

Launchd 任务

在侧边栏浏览用户 Agent、系统 Agent 与 LaunchDaemon。可导入 .plist 或粘贴 XML（含 AI 助手生成的内容），也可从 New 菜单新建。用表单或 XML 编辑——额外键会保留。在列表中加载、启动、停止；系统级操作需要时会提示管理员权限。

Services（TCP 监听）

在侧边栏打开 Services，扫描本机 TCP 监听与已发布到 Mac 的 Docker 端口。可重命名、打开 URL、停止进程或容器，或从运行中的本地服务创建 Launch Agent。

调度

在同一列表中添加每日、每周、每月、每年、间隔与 WatchPaths 规则。日历、间隔与 WatchPaths 可并存，各规则独立生效。

Login Items

通过 Login Items 说明了解 launchd 与系统登录项的区别，并可快捷打开系统设置。

故障排除

  • 损坏或空的 plist 会在列表中行内提示，支持一键删除。
  • 若 Docker 操作失败，请确认 Docker Desktop 或 Colima 正在运行。应用会搜索常见安装路径并回退到 PATH。
  • 已加载的任务在退出 LaunchManager 后仍由 launchd 运行——应用仅用于配置和控制。

常见问题

关于 LaunchManager 的常见问题。

LaunchManager 是什么？

一款原生 macOS 应用，可视化管理 launchd 任务、后台服务以及你用 AI 搭建的自动化——可导入或粘贴 plist，用表单或 XML 编辑，并控制运行。

可以从 AI 助手导入 plist 吗？

可以。从工具栏导入 .plist 或粘贴 XML，再用表单或 XML 编辑，并在列表中加载/启动/停止。

退出应用后，任务还会继续运行吗？

会。已加载的任务由 launchd 负责运行，LaunchManager 仅用于配置和控制。

运行需要什么环境？

macOS 14 及以上，可通过 Homebrew、DMG 或从源码构建安装。

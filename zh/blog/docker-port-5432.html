为什么 Docker 一直占用 5432 端口

5432 是 Postgres 默认端口——旧的 docker compose 栈常会一直占用。

在 5432 上运行本地 Postgres 或应用时发生冲突，往往是旧的 postgres 容器仍在运行。

查找容器

docker ps --filter "publish=5432"
docker ps -a | grep 5432

停止容器

docker stop <container_name>

若 lsof 显示 Docker 代理

监听进程可能是 com.docker.backend。应停止容器，不要结束该 PID。

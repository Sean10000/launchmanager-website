在 macOS 上修复 EADDRINUSE

EADDRINUSE 表示该地址:端口已被其他进程绑定——按此路径排查。

错误信息中包含端口号（如 3000、5173、8080），从这里开始。

1. 确认端口

例如 :::5173 → 端口 5173。

2. 查找监听进程

lsof -nP -iTCP:5173 -sTCP:LISTEN

3. 判断类型：普通进程、Docker 或 launchd

  • 普通应用 — kill PID
  • Docker — docker stop
  • launchd — 卸载任务，避免反复重启

4. 验证

lsof -nP -iTCP:5173 -sTCP:LISTEN

无输出表示端口已释放。

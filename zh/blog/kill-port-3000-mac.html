如何在 macOS 上结束占用 3000 端口的进程

3000 是 React、Next.js 等常用开发端口——这样释放它。

运行 npm run dev 时出现 Error: listen EADDRINUSE: address already in use :::3000，说明 localhost:3000 已被监听。

步骤 1：查找进程

lsof -nP -iTCP:3000 -sTCP:LISTEN

注意 PID 与 COMMAND。常见原因：残留的 node、其他开发服务器，或 Docker 转发 3000 端口。

步骤 2：安全停止

kill <PID>

若命令为 com.docker，请用 docker stop 停止容器。

步骤 3：避免反复出现

若 launchd 会重新拉起进程，请在 LaunchManager 中卸载对应 LaunchAgent。

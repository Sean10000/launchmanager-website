Port Manager for macOS

See every TCP listener on localhost, match ports to processes, and fix conflicts — without memorizing lsof flags.

The problem

You start a dev server and get EADDRINUSE. Something is already on port 3000, 5173, or 8080 — but Activity Monitor does not show ports, and lsof output is hard to scan.

Do it visually in LaunchManager

Browse startup items, launchd jobs, ports, and Docker — then load, stop, or fix conflicts from one native app.
